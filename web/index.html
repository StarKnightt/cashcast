How the numbers are made

  1. Cashcast reads your invoice history: client, issue date, due date, amount, paid date.
  2. For every invoice it computes what you knew on the day you sent it: how that client paid before, how many of their invoices were still open, the amount compared with their usual.
  3. TabPFN, an open tabular foundation model, learns from your paid invoices in one pass (no training loop) and returns a full distribution of days to payment for each open one.
  4. Code turns that distribution into a late-payment chance, a payment date range that accounts for how long the invoice has already been open, and a weekly cash forecast.

    Use it on your own invoices

    Local mode is on. Your file is read by the Python process on this computer and is not sent anywhere else.

    No file at hand? or download it to see the format.

    This page is static, so it cannot read your file. Run Cashcast on your laptop instead; it needs Python 3.10 or newer and works on a CPU.

    git clone https://github.com/StarKnightt/cashcast
cd cashcast
pip install -r requirements.txt
python -m cashcast.serve      # opens http://localhost:8765

    Your CSV needs one row per invoice with the columns client, invoice_id, issued, due, amount, paid. Leave paid empty for invoices that are still open. Download a sample CSV.
